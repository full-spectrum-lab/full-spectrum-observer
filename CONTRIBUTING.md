# Contributing

## Branch and commit rules

- Feature branch: `feat/IMP-xxxx-short-name`
- Fix branch: `fix/DEFECT-xxxx-short-name`
- Commit: `IMP-xxxx: imperative summary`
- Tests must reference a `TR-FK-*` identifier in the test name or metadata.

## Stop conditions

Do not commit:

- floating dependency versions;
- build output or private Python binaries;
- secrets, raw enterprise input, or private enterprise data;
- a second implementation of formal governance calculation;
- direct Python worker invocation outside `Observer.EngineFacade`;
- Console, HTTP, Copilot, Connector, Registry, microservice, MQ, or cloud-control-plane work.

## Community evidence task

The [Observer v0.4 community evidence task](docs/community/observer-v04/COMMUNITY_EVIDENCE_TASK.md) is an ongoing, non-blocking evidence activity. Its execution phase is not open until the Owner separately authorizes an exact candidate, checksum, scope and distribution method.

Expressions of interest and later evidence contributions must not contain raw data, reversible redactions, private keys, credentials, cookies, personal paths or unapproved screenshots. Failures, disagreement, `REJECT` and `UNKNOWN` are valid evidence and must not be rewritten as success.

See the [Chinese participant runbook](docs/community/observer-v04/PARTICIPANT_RUNBOOK.zh-CN.md) for the detailed procedure.
